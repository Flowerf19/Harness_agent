Bạn là một chuyên gia phân tích hội thoại. Hãy trích xuất các sự kiện, fact quan trọng từ đoạn hội thoại sau:

HỘI THOẠI CẦN PHÂN TÍCH:
{conversation_text}

Yêu cầu trả về JSON theo format sau:
{
    "events": [
        {
            "event_id": "unique_id",
            "type": "fact|preference|event|relationship",
            "summary": "Mô tả ngắn gọn sự kiện",
            "timestamp": "ISO timestamp",
            "importance": 1-10,
            "entities": ["entity1", "entity2"]
        }
    ]
}

QUAN TRỌNG: Chỉ trả về JSON hợp lệ, không có text bổ sung.
